# .github

This is the **[AgentSwarms-fyi](https://github.com/AgentSwarms-fyi)** organization's special `.github` repository.

GitHub uses repositories named `.github` to hold org-wide defaults and community health files that apply across every repo in the organization (unless a repo defines its own).

### What lives here

| Path | Purpose |
| --- | --- |
| [`profile/README.md`](./profile/README.md) | Rendered as the **[organization profile page](https://github.com/AgentSwarms-fyi)** |
| [`assets/`](./assets) | Logo, banner, and screenshot assets used by the profile README |

### Updating the org profile

Edit [`profile/README.md`](./profile/README.md) — that's the file GitHub renders on [github.com/AgentSwarms-fyi](https://github.com/AgentSwarms-fyi). This root `README.md` is just documentation for this repository itself and is not shown on the profile page.
